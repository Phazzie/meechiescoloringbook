## Row 2 — same suite, `--config=pw.local.config.ts`, pointing at the installed Chromium 1194

The override is an untracked scratch file, so it is reproduced verbatim below rather than described:
a claim about a file nobody can open is not evidence. Against the committed `playwright.config.ts`
it absolutises `testDir` and adds `webServer.cwd` (it lives outside the repository, so relative
paths would not resolve), and it flattens `process.env.CI ? 1 : 2` and `!process.env.CI` to the
values they already take here, where CI is unset. Its one behavioural difference is
`launchOptions.executablePath`. Test selection, worker count, retries and the base URL are the
committed config's.

An earlier version of this section claimed the override "sets only `launchOptions.executablePath`".
That was false of the file's text, and it is recorded rather than quietly replaced.

```ts
// Scratch-only Playwright override. Lives OUTSIDE the repo on purpose: an earlier run swept a
// root-level copy of this into a commit with `git add -a`. The container ships Chromium 1194 while
// @playwright/test pins 1208, so the mandated `npx playwright test` cannot launch a browser here;
// this points at the installed one so the suite can still be run and reported.
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
	testDir: '/home/user/meechiescoloringbook/tests/e2e',
	fullyParallel: false,
	workers: 2,
	retries: 0,
	webServer: {
		command: 'npm run dev -- --host 127.0.0.1 --port 4173',
		cwd: '/home/user/meechiescoloringbook',
		url: 'http://127.0.0.1:4173',
		reuseExistingServer: true,
		timeout: 180000
	},
	use: { baseURL: 'http://localhost:4173' },
	projects: [
		{
			name: 'chromium',
			use: {
				...devices['Desktop Chrome'],
				launchOptions: { executablePath: '/opt/pw-browsers/chromium' }
			}
		}
	]
});
```
