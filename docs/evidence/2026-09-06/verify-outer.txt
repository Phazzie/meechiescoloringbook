#      written after the chain returns and is absent from that chain's inventory. Capturing it
#      in place instead made proof-tape record 1901 bytes for a 1908-byte file - it had not yet
#      seen this file's own closing exit line. The convention and capture order are recorded
#      in docs/evidence/README.md so a future run does not have to rediscover them.
