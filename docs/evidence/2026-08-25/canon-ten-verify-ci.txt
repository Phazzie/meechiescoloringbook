WHY THE LOCAL RUN DIFFERS
-------------------------
Locally `npm run verify` stops at verify:runner on one test:
  tests/unit/api-generate.test.ts > "keeps the endpoint parse and input guards
  transport-thin" — Test timed out in 5000ms.

Measured, not assumed:
  npx vitest run tests/unit/api-generate.test.ts -t "transport-thin" --testTimeout=120000
  -> 1 passed. Duration 6.79s, of which 5.83s is test time and ~2.8s is user CPU.

So the test spends most of its wall time waiting, not computing, and lands just
past the 5000ms default. That endpoint performs HTTP with retry and backoff, and
this container routes outbound traffic through a proxy, which is what pushes it
over. The same test passes on CI, and it fails identically on a clean checkout of
the base commit (verified by stashing this branch's changes), so it predates this
work and is not caused by it.

changes a shared gate for every future contributor to paper over a local quirk.
