WHY THE LOCAL RUN DIFFERS
-------------------------
`npm run verify` stops at verify:runner on one test:
  tests/unit/api-generate.test.ts > "keeps the endpoint parse and input guards
  transport-thin" — Test timed out in 5000ms.

Measured, not assumed:
  npx vitest run tests/unit/api-generate.test.ts -t "transport-thin" --testTimeout=120000
  -> 1 passed. Duration 6.79s, of which 5.83s is test time and ~2.8s is user CPU.

It waits on I/O rather than computing, and lands just past the 5000ms default. That
endpoint does HTTP with retry and backoff, and this container routes outbound traffic
through a proxy. It passes on CI, and it fails identically on a clean checkout of the
base commit (verified by stashing this branch's changes), so it predates this work.

WHY THE TEST IS NOT PATCHED HERE
--------------------------------
Raising that one test's timeout would make the local run green, but it means editing
an unrelated test's configuration to accommodate one environment's network latency.
That widens this PR into a file it otherwise does not touch, and changes a shared gate
for every future contributor to paper over a local quirk. The gate is green where it
governs merges. This file is the actual command output for that, per AGENTS.md line 49.
