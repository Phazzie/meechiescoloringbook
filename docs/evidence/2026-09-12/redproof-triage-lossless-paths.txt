Red-proof: the three Codex P2 findings on dfbe4e7, each reintroduced and each caught
====================================================================================

Findings, verbatim in substance:

  1. "Preserve every conflicted filename" (scripts/analyze-merge-conflicts.js) — when two or more
     conflicts share a directory the cell replaces their names with `dir/* (N files)`, so the table
     no longer holds the files git named and a reviewer cannot audit the conflict without rerunning
     the analyzer. Remedy offered: keep the complete list, or link to lossless evidence.
  2. "Validate PR cells in the dry-run reader" (scripts/validate-pr-backlog.js) — the second reader
     never calls findRowsWithBadPrCell, so a full-width row written `348` instead of `#348` is
     omitted from prRows, selectCleanCandidates returns an empty list with no reason, and main
     exits 0 as though no validation were requested.
  3. "Reject duplicate decision headers" (scripts/validate-pr-backlog.js) — parseTableColumns keeps
     the first index for a repeated name, so a header carrying `Dry-run` twice lets one row answer
     yes and no at once, with the earlier column silently winning.

All three confirmed by reading the code. Fix for 1: the cell keeps the readable summary and the
complete list is written verbatim into a delimited block below the table, in the same run, from the
same measurement; the analyzer refuses to measure a table with nowhere to put it. Fixes for 2 and 3:
the validator gains the guards the analyzer already had, and findDuplicateColumns now takes the
column names its caller reads instead of hard-coding the analyzer's three.
